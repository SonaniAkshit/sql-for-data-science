# SQL for Data Science

A structured SQL learning and practice repository focused on data extraction, cleaning, analysis, and Machine Learning preparation.

---

## Purpose

This repository is designed to help you:

- Learn SQL from fundamentals to advanced level
- Build strong data querying and analysis skills
- Perform data cleaning and exploratory analysis using SQL
- Prepare datasets for Machine Learning
- Crack Data Scientist / Data Analyst interviews
